# Roadmap — Megawatt Valley (true-3D)
Updated 9 October 2026. **Three.js/Electron is the sole current implementation direction.** Historical Phaser/Unity roadmaps are archived in Git history.

## Milestone 1 — Accept the playable Solar Level 1
- Complete independent playtest and screenshot review at normal and laptop resolutions.
- Correct actual UX/visual blockers against issue #13 and `Docs/DESKTOP_QUALITY_TARGET.md`.
- Validate onboarding, 30–60 minute progression and staff/maintenance/research choices.
- Verify native Windows save/close/resume, import/export, offline assets and recovery.

## Milestone 2 — Consolidate architecture and repository
- Archive and remove obsolete Unity/Phaser implementations and workflows with clean-clone tests.
- Reduce to one primary Three.js UI/runtime, one reliable CI/release pipeline and authoritative docs.
- Preserve save compatibility and recoverable archive branches; rebase/retarget stacked PR #11 safely only after review.

## Milestone 3 — Art, feel and performance
- Use professionally made, commercially safe free assets first; verify licence provenance.
- Improve world density, detailed solar assets, character/vehicle work, weather, lighting and audio.
- Establish measured hardware performance budgets and representative populated-world benchmarks.

## Milestone 4 — Public-quality Solar release
- Independent player usability/pacing tests, accessibility pass, installer/security/reinstall checks.
- Store presentation, distribution, credits and release checklist.

## Later: other renewable-energy levels
Wind, storage, portfolio management and new scenarios are future work only, after Solar Level 1 acceptance.
