# Archived Unity Prototype — 29 September 2026

## Status

**ARCHIVED / HISTORICAL REFERENCE**

The Unity implementation of Megawatt Valley is no longer the primary production path.

The full repository state immediately before the production pivot is preserved on:

**archive/unity-prototype-2026-09-29**

At archive time the Unity project contained a playable grey-box / functional solar slice and engagement/progression work.

## Why it was archived

The project direction changed because the highest-priority constraint became:

> **Finish Megawatt Valley with minimal ongoing manual development effort from Rapha.**

The active production approach is now a browser-first Phaser / TypeScript build designed so Cursor can code, run, visually inspect, test and debug the game without depending on Rapha to operate a game editor.

## What remains valuable

The archived implementation is still useful as:

- behavioural reference;
- proof of earlier gameplay decisions;
- source of balancing/design lessons;
- reference for the solar loop;
- reference for objectives, maintenance and progression;
- historical record.

## What is not active

Do not continue:

- Unity scene development;
- Unity package configuration;
- Unity MCP work;
- Unity-specific asset pipelines;
- Unity-specific camera/prefab/editor work.

unless Rapha explicitly reactivates the Unity branch.
